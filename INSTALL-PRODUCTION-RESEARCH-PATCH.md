# Install — Production research and storyboard patch

This is a cumulative patch: it includes the earlier Production proposal-validation fix plus the deeper Production research/storyboard workflow.

## Install

1. Close the Minecraft Narrative Studio dashboard.
2. Close the launcher and runner terminals.
3. Back up the complete harness folder, especially `videos/the-portal-that-nobody-made`.
4. Extract this ZIP directly into the harness root—the folder containing `START-STUDIO.ps1`, `mcstudio`, `studio`, `templates`, and `videos`.
5. Choose **Replace the files in the destination**.
6. Start the dashboard normally.

The patch does not include or modify `capture-log.csv`, captured media, approvals, local runner settings, API keys, or third-party mod files.

## Run the deeper Production pass

1. Open **Production → Studio Assistant**.
2. Set **Mode** to **Develop phase**.
3. Set **Research** to **Allow web search**.
4. Paste the prompt from `STUDIO-ASSISTANT-PRODUCTION-DEEPENING-PROMPT.md`.
5. Run Studio Assistant. A web-enabled run prioritises Codex, then the direct OpenAI runner, before OpenCode.
6. Review the proposal. It should update the main Production plan and the dedicated research, implementation, test, storyboard, camera, location, asset, budget, risk and build records.
7. Accept only after checking that every claim distinguishes sourced individual support from integrated tested compatibility.

## After accepting

Do not advance to Edit yet. Start with the isolated version/mod proof of concept in `test-matrix.csv`. Record actual versions, hashes, logs and pass/fail evidence. Keep `capture-log.csv` empty until real footage exists.

No image is generated by this patch or by the supplied Studio Assistant prompt.
