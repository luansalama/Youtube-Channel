# Writing system

The writing system is rigorous without prescribing a universal plot formula.

## Human-facing model

- `direction.md`: promise, premise, Minecraft causality, theme, ending, scope, and research decision.
- `story-plan.md`: chronological story, causal plot, audience presentation, characters, movements, scenes, continuity, and ending.
- `script.md`: the complete production script.

## Hidden checks

The Studio Assistant maintains structured evidence for causal events, sequences, beats, scenes, audience knowledge, setup/payoff obligations, relationships, and continuity. These records support deterministic audits but do not clutter the normal workspace.

## Adaptive revision

Every script receives six core checks:

- promise;
- causality;
- dialogue and subtext;
- visual storytelling;
- production feasibility;
- continuity and canon.

Additional checks—such as character agency, escalation, information design, theme, scene necessity, and audience-results planning—activate only when relevant. Optional passes may be explicitly marked not required with a reason.

The system must not enforce fixed page counts, act percentages, exact beat counts, mandatory Hero’s Journey stages, predetermined twist timestamps, or one prescribed emotional arc.
