# Low-budget worldbuilding for a solo creator

## Build the frame, not the continent

Start from required shots. A location is complete when it provides the story's angles, movement, reveal, and sound opportunities—not when it exists as a fully navigable world.

Use four layers:

1. **Hero geometry:** the unique shape audiences remember.
2. **Modular kit:** repeatable walls, arches, props, terrain chunks, doors, cables, trees, debris, or colour accents.
3. **Perceptual extensions:** fog, darkness, shafts, silhouettes, sound, blocked sightlines, texture changes, and distant cards.
4. **Editorial geography:** cuts, eyelines, audio bridges, maps, journals, and repeated landmarks that make disconnected sets feel continuous.

## One hero location rule

For early productions, spend distinctive build effort on one location. Supporting spaces should be variations of modules or natural terrain that frame the hero place. The viewer remembers narrative function and image hierarchy more than block count.

## Scout before building

For landscape-led Minecraft productions, search existing seeds, downloaded worlds and already-generated locations before committing to terrain construction. Score candidates against the locked shots: silhouette, route, camera access, portal chamber, surface relationship, editability and how much must be hidden or imported. The best candidate is the one that minimises irreversible work, not the one that matches every detail naturally.

Importing a ravine, forest section, mountain profile or structure from another seed is allowed when provenance permits it. Treat the imported material as raw geography: keep coordinates documented, blend chunk/biome boundaries, inspect lighting and water, and preserve a pre-import backup. A seed number may be used as a generation reference; an authored downloadable map or schematic requires source and usage-rights records.

## R0-first parallel realities

Do not require a neutral world to be built from scratch when the story uses variations of one place. Select and adapt the best candidate as **R0**, complete the expensive geography shared by every reality, then duplicate R0 into separate working saves. Make the variations through state changes and local dressing. The final filming save may consolidate those working saves as custom dimensions after a transfer proof.

For a near-match ending reality, derive it directly from R0. Example: `R4 = R0 + Home + minor seasonal/state differences`. Do not rebuild shared terrain merely to preserve an abstract pipeline distinction.

## Imply history through state changes

Instead of building many places, show one place in meaningful states:

- untouched;
- disturbed;
- partially understood;
- transformed after the reveal.

Lighting, props, particles, block substitutions, ambient tracks, and camera access can create progression without a new map.

## Make limitations part of the fiction

Narrow tunnels, incomplete archives, darkness, sealed doors, missing chunks, restricted render distance, corrupted recordings, or a character avoiding open terrain can be narratively justified. Use each device sparingly and establish rules so it feels authored rather than convenient.

## Minecraft versus Blender

Prefer Minecraft capture for embodied exploration, interaction, and recognisable game logic. Use Blender for shots that benefit from precise lensing, isolated hero assets, impossible transitions, controlled particles, or extensions that would be expensive to build in-game.

Do not turn every shot into a Blender shot. The contrast can weaken the reality of the Minecraft world and multiply technical risk.

## Reuse without visible repetition

Change camera height, access direction, light state, fog, dressing, sound, and focal action before rebuilding geometry. Track module usage in the asset register so repeated production value becomes deliberate intellectual property rather than accidental recycling.

## Build-risk test

Before approving a location, answer:

- Which exact shots require it?
- What is the minimum camera-visible geometry?
- Which module survives into later videos?
- Can sound or editing imply the missing scale?
- What is the fallback if the hero build takes twice the estimate?
- Does the reveal depend on a construction trick not yet proven?

Prototype the hardest trick before finishing decoration.
