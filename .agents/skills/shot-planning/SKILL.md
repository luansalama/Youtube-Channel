# Shot Planning

## Outputs
`05-preproduction/shot-list.csv` and later `07-capture/camera-paths.csv`.

## Method
Assign stable shot IDs tied to beat/scene IDs. Record location, framing, movement, action, dialogue/VO, duration, method, assets, and status. Group by set state and technical setup without breaking story performance. Include handles, clean plates, inserts, transitions, ambience, and safety shots.

## Acceptance
Every scripted visual is covered; every shot is feasible; no asset lacks provenance; recapture can be reconstructed from the log.
