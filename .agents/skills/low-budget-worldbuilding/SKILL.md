# Low Budget Worldbuilding

## Strategy
Scout existing seeds, worlds and generated locations before building. Select the closest camera-feasible hero location, adapt it as R0, import only missing terrain or structures where useful, then use modular surfaces, camera-safe directions, state changes, blocked sightlines, fog/darkness, silhouettes, sound extensions, and editorial geography. For parallel realities, duplicate the approved R0 rather than constructing five landscapes from scratch.

## Deliverable
For each location state story function, hero angle, visible geometry, modules, lighting states, implied off-screen world, estimated hours, reuse value, and fallback.

## Prototype first
Test the signature visual/reveal before detailed decoration. Cut supporting geometry before compromising the hero shot or finishing the film.
