# Youtube Packaging

## Outputs
Files under `.studio/internal/release/`.

## Method
Begin from the film's strongest honest question. Pair title and thumbnail as one promise. Produce three distinct propositions, test ambiguity and mobile readability, then choose with rationale. Metadata uses en-GB and verified credits/claims. Chapters come from the locked master.

## Release
Generate a checksummed package, dry-run the API request, upload privately only with explicit instruction, inspect processing, then complete the release record. Never auto-publish.
