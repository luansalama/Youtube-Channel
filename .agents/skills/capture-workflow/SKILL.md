# Capture Workflow

## Outputs
Capture, camera-path, and audio logs with stable filenames.

## Rules
Pin the world/tool versions. Never overwrite selected takes. Record take, file, date, technical status, performance status, selection, and notes. Capture room tone/ambience, clean plates, handles, and a safety take for irreplaceable moments. Back up world and project state before destructive changes.

## Stop
Do not proceed to edit with unknown missing shots; list explicit pickup requirements.
