# Minecraft Production Design

## Outputs
Location plan, asset register, risk register, build budget, and location cards.

## Method
Start from locked shots. Decide what must be in Minecraft, what may be Blender, and what can be implied through edit/sound. For landscape-led work, scout seeds and existing worlds first; score camera access and edit distance, select the closest location as R0, import missing geography when efficient, and duplicate only after shared camera-visible geography is stable. Pin versions and test the hardest technical bridge early. If realities must coexist for filming, plan separate working saves, custom-dimension registration, controlled chunk transfer and a filming master. Build hero geometry, a modular kit, perceptual extensions, and editorial geography. Track provenance and reuse.

## Constraint
Do not design unseen world detail merely for completeness. Every expensive element needs shot IDs and a fallback.
