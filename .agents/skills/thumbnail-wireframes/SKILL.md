# Thumbnail Wireframes

## Inputs and output
Populate `.studio/internal/release/thumbnail-concepts.json`; run `python -m mcstudio --root . thumbnail-wireframes <slug>` to generate SVG layout diagrams.

## Method
Each concept expresses one visual question, one dominant subject, one secondary tension, a clear hierarchy at small size, and zero-to-four words. Concepts must be materially different, not colour variants.

## Hard rule
SVGs are disposable wireframes. Final thumbnails use authored Minecraft captures, Blender renders, typography, photography, or properly licensed assets—never AI-generated final art.
