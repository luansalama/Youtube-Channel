# Analytics Review

## Inputs
YouTube Studio CSV exports in `data/analytics/video_snapshots.csv`, release context, and postmortems.

## Method
Run import/report commands. Distinguish metric observation, plausible explanation, disconfirming evidence, and next experiment. Compare like-for-like windows where possible. Consider catalogue age, traffic source, packaging, opening retention, runtime, and production cost.

## Never
Fabricate benchmarks, claim causality from correlation, optimise only CTR, or recommend a brand change from one upload.
