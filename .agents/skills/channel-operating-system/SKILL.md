# Channel Operating System

## Procedure
1. Read `AGENTS.md`, `studio/studio.json`, and the active video status.
2. Identify the single constraint currently limiting throughput or quality.
3. Work through existing artefacts and commands; do not invent a parallel tracker.
4. Separate reversible drafts from consequential actions.
5. End with changed files, tests/gates, owner, and next human decision.

## Rules
- One source of truth per datum.
- Prefer improving a proven bottleneck over adding speculative automation.
- Never collapse creative approval, factual verification, and publishing authority into one agent action.
