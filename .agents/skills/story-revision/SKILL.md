# Story Revision

## Inputs

Locked or review-ready outline/script, `revision-pass-status.json`, continuity evidence, production plan when available, and recorded audience evidence when revising a released pattern.

## Method

Run one pass at a time: promise, causality, character agency, escalation, theme/change, information, scene necessity, dialogue/subtext, visual storytelling, production feasibility, continuity/canon, and audience-results plan.

For each pass record evidence, diagnosis, decision, changed files, unresolved uncertainty, and whether upstream approval must be reopened. Do not repair dialogue while ignoring a broken causal spine. Do not repair production cost by silently changing the audience promise.

## Output rule

Mark a pass `complete`, `not_applicable` with a substantive rationale, or `blocked`. Never mark complete merely because no edit was made.
