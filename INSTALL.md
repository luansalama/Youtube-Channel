# Install the OBS sound-plan patch

Copy the `videos` folder into the root of the existing Minecraft Narrative Studio harness and allow these two files to be replaced:

- `videos/the-portal-that-nobody-made/.studio/internal/edit/sound-plan.md`
- `videos/the-portal-that-nobody-made/.studio/internal/production/audio-capture-log.csv`

The patch does not alter the script, story, production plan, dashboard code or existing evidence logs.
